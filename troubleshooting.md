# Устранение неполадок

В этом документе собраны решения частых проблем, с которыми вы можете столкнуться при запуске или использовании React Mini Projects.

## Установка и запуск

### `npm start` выдает ошибку `Port 5173 is in use`
**Признак.** При запуске проекта через Vite вы видите в терминале сообщение:
`Port 5173 is in use. Trying another port...` или приложение не открывается по адресу `http://localhost:5173/`.

**Причина.** Порт 5173 уже занят другим процессом. Это может быть другой экземпляр React-приложения, работающий в фоне, или другое приложение на вашем компьютере.

**Решение.** 
Сначала проверьте, не открыт ли у вас другой терминал с запущенным проектом (закройте его). Если нет — завершите процесс, занимающий порт:
- **Windows:** `netstat -ano | findstr :5173`, затем `taskkill /PID <номер_процесса> /F`
- **Mac/Linux:** `lsof -i :5173`, затем `kill -9 <PID>`

**Проверка.** Запустите `npm run dev` снова. В терминале должно появиться:
`VITE v... ready in ... ms` и `➜ Local: http://localhost:5173/`
